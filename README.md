# Jio TV Web

A modern web-based interface for accessing Jio TV content through Sportlink integration.

## 🚀 Live Demo

[Sportlink Jio TV Mini](https://sportlink-jio-tv-mini.pages.dev/)

## 📋 About

Jio TV Web is a streamlined web application that provides access to Jio TV channels through the Sportlink platform. The interface is designed to be user-friendly and responsive, allowing users to watch their favorite content seamlessly.

## ✨ Features

- 📺 **Live TV Streaming** - Access to various Jio TV channels
- 🎯 **Easy Navigation** - Simple and intuitive user interface
- 📱 **Responsive Design** - Works on desktop and mobile devices
- 🔍 **Search Functionality** - Find channels quickly
- 🌤️ **Weather Display** - Real-time weather information included

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Sportlink API Integration

## 🚦 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sayanpal514-hue/Jio-Tv-Web.git
```

2. Navigate to the project directory:
```bash
cd Jio-Tv-Web
```

3. Open `index.html` in your browser or use a local server.

### Using the Application

1. Visit the [live demo](https://sportlink-jio-tv-mini.pages.dev/player?id=544)
2. Browse through available channels
3. Click on a channel to start streaming
4. Use the search bar to find specific channels

## 📝 Configuration

The application can be configured by modifying the following:
- `id` parameter in the URL for different channel IDs
- CSS variables for custom styling
